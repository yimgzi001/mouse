# Windows 手势鼠标

Go 编写的本地手势鼠标。当前已接通：摄像头 → ONNX 双手关键点 → 手势识别 → 可配置动作引擎 → Windows 鼠标与键盘输入，配有 Windows 原生配置面板。视频仅在内存处理，不保存、不上传。开发状态与专题资料见[文档入口](docs/README.md)。

## 直接运行

系统要求：Windows 10/11 x64、可用摄像头。当前构建产物为 `bin/mouse.exe`，同目录的 `runtime` 文件夹须保留。

```powershell
.\bin\mouse.exe
```

默认打开 Windows 原生配置面板，摄像头预览由面板“实时预览”按钮显示/隐藏。面板与预览关闭只会隐藏，F7 可重开面板；F8 暂停/恢复，F9 或面板“退出”结束程序。需要启动时同时看图像可用 `-preview`；`-panel=false` 可关闭配置面板，单独预览时关闭窗口仍会退出。

下表是初始化时的默认方案，实际运行以面板保存的绑定为准。

| 手势/按键 | 操作 |
|---|---|
| 单只手只伸食指 | 相对移动鼠标；左右手灵敏度可分别设置 |
| 左手握拳 | 单击左键；保持不会连发，松开后才能再次点击；右手可继续定位 |
| 右手拇指与食指捏合，另三指收起 | 备用左键单击方式 |
| 左手伸食指和中指 | 单击右键 |
| 右手伸食指和中指并移动 | 按住左键拖拽；收起或撤手后松开 |
| 三指（食指、中指、无名指）上下移动 | 滚动页面；手停则停 |
| 右手五指张开 | 连续确认后打开原生窗口切换器，随后按右掌心左右移动选窗，手指可放松 |
| 窗口切换中右手握拳 | 确认并切到当前高亮窗口；兼容撤右手约 400ms（丢手宽限）后确认 |
| 右手四指伸直并拢、拇指收起，快速向右挥 | 直接快切一次，相当于 Alt＋Tab；向左挥为 Alt＋Shift＋Tab 反向快切 |
| 同时伸出两只手的食指 | 拉开放大、合拢缩小，相当于 Ctrl＋滚轮；缩放时冻结光标，两只手一起平移不会缩放 |
| 左手只伸中指，其余手指收起 | Tab，每次手势一次；收回成拳不顺带点击 |
| 右手只伸中指，其余手指收起 | Enter，每次手势一次 |
| 右手后三指：中指、无名指、小指伸直，食指收起，拇指随意 | 单击右 Alt，每次手势一次，立即松开，不保持或附带其他按键 |
| 右手握拳或撤手 | 平时停止右手动作；切屏中表示确认当前选项 |
| F8 | 全局暂停/恢复；选窗时暂停会取消，不切换到选中项 |
| F6 | 交换左右手识别标签；先用真实左手核对预览再调整 |
| F7 | 显示原生配置面板 |
| F9 / 面板退出 | 退出并释放程序持有的输入；调试控制台运行也支持 Ctrl+C |

默认捏合额外确认 80ms，左拳左键与左手两指右键 100ms，右手两指拖拽 120ms，三指滚动 100ms；双食指缩放确认 100ms。以上均在手势投票确认后计时。中指键单独连续确认至少 60ms，右手后三指至少 80ms；保持只触发一次，松开再做才能重发。旧的拇指向上 Tab 已取消；原 OK 手势已由后三指取代，默认左手后三指无键盘动作。识别设置和绑定等待可在面板分别修改，下述行为同样描述默认方案。

五指单独采用至少两帧、跨度至少 150ms 的连续识别确认，从其他手势直接换成五指时至少 300ms，不受之前其他手势的投票拖延；单帧误识别不会唤出，丢手、换姿态或采样间隔超过 150ms 会重计。以上时间都是识别确认门槛，实际响应还包含摄像头、推理及 Windows 处理耗时。三指采用食指、中指、无名指，不是拇指、食指、中指。

新出现的手（刚进入画面，或离开超过丢手宽限后重新出现）前 200ms 只移动指针，点击、按键、拖拽、滚动、切屏等其他动作在观察期结束后才生效。掌宽（手腕到中指根）不足 45 像素的新手不予跟踪，避免身后远处的人误触；已在跟踪的手不受掌宽限制，转动或快速移动时也更不容易丢失。左右手标签稳定 0.5 秒后锁定，需要连续 0.7 秒的相反判断才翻转。同一只手被重复检测时合并为一个，不会占两个跟踪位。手离开画面不超过丢手宽限（默认 400ms）并在附近重新出现时保持原状态。新手观察时间、最小掌宽和丢手宽限可在面板修改。

切屏只由右手控制。选窗唤出后跟随右掌心，不再要求每帧保持五指，避免拇指在四指/五指之间跳变导致停止跟随。左手不抢选窗，左右手不确定或短暂丢手时冻结，右手握拳确认。选窗过程中左拳不点击、左中指不发 Tab；如果持续保持，确认后也不补发，须先松开再做。左中指 Tab 收回为拳也不补点，先张手再握拳可恢复正常单击。短暂丢手不重复点击，单帧握拳或未知左右手不会点击；只伸拇指的未绑定方向也不会被当作拳触发左键。

四指掌快切按挥动轨迹触发，默认在 250ms 内水平移动约 0.65 掌长；缓慢平移或上下移动不触发。回摆有 350ms 防重复。手势切换和短暂丢手会重建轨迹，避免把之前的移动当成快切。快切完成即释放 Alt；五指选窗模式则保持选窗，握拳后才确认。切屏滑块同时控制选窗步距和四指挥动阈值。

建议先用物理鼠标点到浏览器页面，再试滚动或缩放；这些操作由当前应用处理，预览窗口本身没有网页可滚动。窗口切换 8 秒未选择新项会取消；保持五指不会立即重开，需要先收起再张开。切屏优先于双食指缩放。缩放单帧最多输出两步，短暂丢手或左右手不确定时冻结，恢复后重新建立距离基准。

## 独立灵敏度

预览窗口下方有六个滑动条：左手移动、右手移动、拖拽、滚动、切屏、缩放。范围均为 0.1～5，松开滑块后立即生效并保存。调节前可按 F8 暂停，暂停时仍能看识别结果。

默认移动左/右 0.5、拖拽 0.5、滚动 1.0、切屏 2.5、缩放 1.0。切屏默认选中项步距约为原来的 40%，最小步进间隔为 70ms，跟随更快。修改设置会释放正在按住的按钮/按键并重建基准。

设置默认保存在 EXE 同目录的 `settings.json`，现在为版本 3，包含六项倍率、左右手校正、识别设置和绑定。旧七字段配置和版本 2 配置读取时自动升级，版本 2 里的 OK 绑定改为后三指；新程序启动时即写回版本 3，原文件分别备份为 `settings.json.v1.bak`、`settings.json.v2.bak`，已有备份不覆盖。旧程序读不了版本 3 配置，回退方法见[当前架构与配置](docs/architecture.md)。可用 `-config` 指定路径。`-sensitivity` 仅在显式传入时覆盖左右手移动，不影响拖拽或自定义映射。

## 原生配置面板与手势绑定

- **手势绑定**：新增、删除、启停、改名，选择左/右/任意手或双手、手势、触发方式和动作。动作参数按目录动态显示，可填单键/组合键、鼠标键、倍率、方向等；高级列表可配置返回姿势保护。
- **灵敏度与识别**：六项基础倍率及七项识别设置（投票窗口、丢手宽限、中指/后三指/五指确认时间、最小掌宽、新手观察时间）分别编辑。动作内倍率默认 1，与对应基础倍率相乘一次；例如左手基础 0.5 × 动作 2 = 实际 1。原生预览滑块、面板及 F6 共享配置服务，不覆盖其他映射。
- **配置管理**：原生文件对话框导入/导出 JSON，导入、恢复默认只修改草稿，按“保存并应用”才生效。默认映射、默认倍率和默认识别设置分别恢复，保留左右手校正。导出不能覆盖正在运行的配置文件。
- 草稿与运行配置分离。保存会校验动作兼容性、重复 ID/触发、按键和数值；失败不替换运行配置。其他入口修改后，过期草稿会被拒绝覆盖，可先导出草稿再重载。
- 首版识别十种基础手势及双食指组合，动作绑定启停不改变识别结果。双食指缩放也是普通绑定，可禁用或改为一次性按键/点击；禁用后不抢指针。首版不编辑新几何手势或训练模型。
- 保存时释放拖拽和 Alt，保留暂停状态与已保持手势的消耗状态；不因保存、改键或 F6 对同一个保持姿势补发点击、Tab 或其他键。按键返回保护、选窗占用保护同样适用于可配置触发方式。

例如选择“左中指 Tab”，把按键参数 `tab` 改成 `esc`，点击“保存并应用”，以后左中指发送 Esc，重启也保留；默认设置不再在程序启动时覆盖它。

首次体验建议让摄像头正对双手，保证光照。预览显示当前手势、正在运行的动作和最近触发记录；修改后的映射以面板绑定列表为准。`-verbose` 会打印输入动作和识别状态变化（原始手势、稳定手势、左右手、丢手、手指状态），并保留每秒采样，便于核对短暂中指手势未触发的原因。图像推理只在本地运行。

```powershell
# 查看摄像头编号（不采集画面）
.\bin\mouse.exe -list

# 诊断 10 秒，仅输出动作，不发送真实输入
.\bin\mouse.exe -dry-run -verbose -seconds 10

# 打开实时预览核对手的位置、关键点和左右手标签
.\bin\mouse.exe -preview

# 以暂停状态启动，按 F8 开始
.\bin\mouse.exe -paused

# 选择其他摄像头、降低灵敏度
.\bin\mouse.exe -camera 1 -sensitivity 0.7

# 仅在确认实际左右手与日志标注相反时启用；本机当前使用默认映射
.\bin\mouse.exe -swap-hands -verbose
```

默认请求 640×480、30 FPS，推理使用两个线程；也可用 `-width`、`-height`、`-fps`、`-threads` 调整。完整参数见 `-help`。

摄像头故障、连续 2 秒收不到帧、推理结果超过 200ms 或 Windows 输入调用失败时，程序停止输入并退出。退出时先释放鼠标输入，再等待摄像头清理；若驱动卡住，最多等待 2 秒后退出进程，由系统回收设备资源。短暂丢手时冻结鼠标，重新识别后重建位移基准；未完成的点击重新计时，已经完成的点击保持锁定。暂停仍保持摄像头打开；预览可见时继续识别显示，预览隐藏时默认跳过推理。如果配置了启用的“手势暂停/恢复”绑定，则继续观察，保证能通过该手势恢复。隐藏预览不转换像素，不新增视频编码或网络传输。

Windows 的 [SendInput 完整性级别限制](https://learn.microsoft.com/windows/win32/api/winuser/nf-winuser-sendinput)可能阻止普通权限程序向管理员权限窗口发送点击。

摄像头输入和默认映射已获用户真人测试确认；原生面板及绑定编辑已通过自动化与原生控件测试，仍待用户本轮试用。识别修复（后三指、新手观察、左右手锁定等）已通过自动化测试和图片回放，尚待真人试用。完整状态、待验收事项和证据见[文档入口](docs/README.md)、[面板验收记录](docs/native-panel-validation-2026-11-17.md)及[识别修复记录](docs/recognition-fixes-2026-11-17.md)。

## 从源码构建

需要 Go 1.27.2、GCC/MinGW（CGO 摄像头采集）及项目 `runtime` 下的 ONNX Runtime DLL。两个 ONNX 模型会嵌入 EXE。

```powershell
go build -ldflags="-H=windowsgui" -o bin/mouse.exe ./cmd/mouse
New-Item -ItemType Directory -Force bin/runtime
Copy-Item runtime/onnxruntime.dll,runtime/onnxruntime_providers_shared.dll bin/runtime
```

也可以在项目根目录执行 `go run ./cmd/mouse -preview -verbose -config mouse-settings.json`，使源码运行使用固定的设置文件。

GUI 产物双击不打开控制台；需要终端日志可用 `go run`，或显式重定向产物输出。无界面诊断可加 `-panel=false`。

## 性能

默认两线程，模型只在推理过程中忙等，一轮推理结束后休眠以降低帧间 CPU 空转。保留 640×480、30 FPS 及全部手势配置。实测数据、CPU 统计口径和延迟取舍见 [性能检查记录](docs/performance-2026-11-17.md)。

程序启动时把自身设为“高于正常”优先级，并关闭 Windows 对它的节能降频，减少其他程序繁忙时的处理延误；设置失败只记日志，不影响运行。跟踪单手时每 66ms 找一次第二只手，图片回放中单手整机 CPU 比上一版高约 1.2 个百分点，见[识别修复记录](docs/recognition-fixes-2026-11-17.md)。

可用固定测试图片复测无手/单手/双手，不打开摄像头或发送输入：

```powershell
go run ./cmd/perfcheck -frames 180 -threads 2 -spin run
# 对比旧线程等待方式
go run ./cmd/perfcheck -frames 180 -threads 2 -spin always
```

测性能时请先退出另一份摄像头程序，先后执行，避免同时测试干扰。输出的 CPU 为整机归一化占用，跟踪耗时不代表用户手势到目标应用的完整延迟。

## 验证

```powershell
go test -count=1 ./...
go test -race -count=1 ./...
go vet ./...
go run ./cmd/visioncheck
```

原生面板和预览控件交互测试需开启环境变量；使用临时配置和控件消息，不发送全局桌面输入：

```powershell
$env:MOUSE_PANEL_TEST='1'
$env:MOUSE_PREVIEW_TEST='1'
go test -race -count=1 ./...
Remove-Item Env:MOUSE_PANEL_TEST,Env:MOUSE_PREVIEW_TEST
```

普通测试不移动真实指针。原生输入集成测试需主动开启，会创建临时测试窗口，只在该窗口内移动和点击，结束后恢复指针位置；执行时请勿移动真实鼠标。

```powershell
$env:MOUSE_LIVE_TEST='1'
go test -count=1 -run '^TestLiveDesktopPointerAndClicks$' -v ./internal/wininput
Remove-Item Env:MOUSE_LIVE_TEST
```

识别链路测试使用 `testdata/reference/control_hands.json` 中的真实 ONNX 输出，同时包含图像和三维关键点；可由 `go run ./cmd/visioncheck -dump tmp/control-capture.json` 生成全量数据，再选取握拳、一指和两指三个样本。
