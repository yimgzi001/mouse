手势鼠标（GestureMouse）使用说明
================================

对着电脑摄像头比手势，就能移动鼠标、点击、滚动、缩放、切换窗口，还能按 Tab、回车、退格等常用键。
解压就能用，不用安装。摄像头画面只在本机内存里处理，不保存、不上传，程序不联网。


一、运行要求

- Windows 10 或 Windows 11，64 位
- 一个能用的摄像头（笔记本自带的或 USB 摄像头都行）


二、开始使用

1. 先把压缩包完整解压到一个文件夹（比如桌面），不要在压缩包里直接双击运行。
   runtime 文件夹要和 GestureMouse.exe 放在一起。
2. 双击 GestureMouse.exe。
   如果出现“Windows 已保护你的电脑”：点“更多信息”，再点“仍要运行”。
   程序没有数字签名，从网上或聊天软件收到的程序第一次运行时 Windows 会这样提示。
3. 出现“手势鼠标”配置面板、摄像头指示灯亮起，就可以用了。
   屏幕右下角（通知区域）会多一个手形图标：蓝色表示手势控制中，灰色表示已暂停。
   图标可能被收进右下角的“^”里，可以把它拖到任务栏上常驻显示。
   关掉面板后程序仍在后台运行：双击图标或按 F7 重新打开面板，按 F9 退出。
4. 光线充足、手完整出现在画面里时识别最好。
   光标旁会有一个小提示，显示认到了什么手势、将要做什么。


三、快捷键

- F8：暂停 / 恢复（暂停时比什么手势都不会触发操作）
- F7：打开配置面板（双击右下角的手形图标也行）
- F6：画面里左右手认反了时按一下，交换左右手
- F9：退出程序（也可以点面板上的“退出”）

右键右下角的手形图标，菜单里有：打开设置、暂停 / 恢复手势、开机时自动启动、退出手势鼠标。


四、默认手势

实际以面板“手势”页为准，那里可以启用、停用，也能改成别的按键。

- 只伸食指（左右手都行）：移动鼠标
- 左手握拳：左键单击（握着不会连点，张开再握才再点）
- 右手拇指和食指捏合，其余三指收起：左键单击（备用）
- 左手伸食指和中指：右键单击
- 右手伸食指和中指上下移动，或左手伸食指、中指、无名指上下移动：滚动页面
- 右手伸食指、中指、无名指并移动：按住左键拖拽，收手后松开
- 两只手都只伸食指，拉开 / 合拢：放大 / 缩小（相当于 Ctrl + 滚轮）
- 右手五指张开停住：打开窗口切换，左右移动手掌选窗口，握拳确认
- 左手只伸小指：Tab 键
- 右手只伸小指：回车键
- 右手只伸中指，横着指向自己的左边：退格键（Backspace）
- 右手伸中指、无名指、小指，食指收起：右 Alt 键

只伸小指就是食指、中指、无名指收起，只竖小指；拇指伸不伸都行，手心手背朝哪边都行。
刚举起的手头 0.2 秒只移动鼠标、不点击，防止误触。


五、设置

- 设置保存在程序旁边的 settings.json。在面板里改完按“保存并应用”就会生效并保存。
- 灵敏度、每个手势的确认时间等都能在面板里调。
- 开机自动启动：右键手形图标，勾选“开机时自动启动”，再点一次就取消。默认不开。
  开了以后，开机时程序直接在后台运行，只显示图标、不弹面板。挪过文件夹后要重新勾一次。
- 想恢复默认：先按 F9 退出，删掉 settings.json，再重新打开。
- 不要解压到 C:\Program Files 这类需要管理员权限的位置，否则设置保存不了；放在桌面或“文档”里就行。


六、常见问题

- 双击后弹出“手势鼠标已退出”：按提示里写的办法处理，常见的有：
  · 摄像头被视频会议、相机等程序占用：关掉它们再打开；
  · Windows 设置 → 隐私和安全性（Windows 10 叫“隐私”）→ 摄像头（相机）：
    打开摄像头访问和“允许桌面应用访问你的摄像头”；
  · 缺 runtime 文件夹：重新完整解压。
- 双击后提示找不到 MFPlat.DLL 或 MF.dll：这是不带媒体功能的 Windows N 版，
  先在“设置 → 应用 → 可选功能 → 添加功能”里装上“媒体功能包”再运行。
- 程序已经在运行时又双击了 GestureMouse.exe：会直接打开正在运行的那个的配置面板，不会开第二个。
- 运行中拔掉了摄像头：程序会等它插回来自动重连，不用重开。
- 在以管理员身份运行的程序窗口里手势不起作用：这是 Windows 的安全限制。
  需要时右键 GestureMouse.exe，选“以管理员身份运行”。
- 杀毒软件拦截：程序会模拟鼠标和键盘输入，个别杀毒软件可能误报，添加信任即可。
- Windows 11 提示“智能应用控制”阻止了程序：这项功能会拦截没有签名的程序，
  只能在“Windows 安全中心 → 应用和浏览器控制 → 智能应用控制”里关掉后运行，关之前请先了解它的影响。
- 有多个摄像头、想换一个：给 GestureMouse.exe 建个快捷方式，在“目标”最后加上空格和 -camera 1
  （编号从 0 开始）。


七、卸载

如果勾过“开机时自动启动”，先右键手形图标取消它；然后按 F9 退出，删除整个文件夹即可。
程序不装服务；只有勾选开机自动启动时才在注册表的当前用户启动项里写一条，取消勾选就会删掉。

第三方组件和许可证见 licenses 文件夹。
