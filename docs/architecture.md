# 当前架构与配置

当前实现采用 Go + Windows Media Foundation + ONNX Runtime + Win32 原生窗口和输入。模型嵌入 EXE，ONNX Runtime DLL 随程序提供；默认摄像头请求 640×480、30 FPS，两线程推理。视频在内存中处理，不保存、不上传。构建、启动及测试命令见[项目使用说明](../README.md)。

## 数据流与模块边界

```text
camera 最新帧 → vision 双手关键点 → gesture 手势状态
                                      ↓
                              control.Controller
                                      ↓
                              engine 绑定与动作
                                      ↓
                              wininput Windows 输入

panel / preview 滑块 / F6 → control.Service → 校验、落盘、运行配置切换
手势状态 + 动作事件 → control.Hinter → overlay 光标旁提示
```

| 位置 | 职责 |
|---|---|
| `cmd/mouse` | 资源初始化、命令行、热键、窗口和进程生命周期；启动时提高进程优先级 |
| `internal/camera` | Media Foundation 采集，只保留最新帧，避免队列积压 |
| `internal/vision` | ONNX 掌心与关键点推理、双手跟踪（重复检测合并、新手最小掌宽）；模型默认在推理结束后停止忙等 |
| `internal/gesture` | 几何分类、左右手跟踪与标签锁定、投票与连续确认；组合检测提供双食指匹配和距离 |
| `internal/control` | 固定识别集合、配置迁移/保存/修订、运行快照和默认预设；绑定的大白话说明和光标旁提示的内容 |
| `internal/engine` | 根据绑定决定动作、资源占用、持续模式和释放保护；新出现的手在观察期内只移动指针；通过 `Injector` 接口输出 |
| `internal/wininput` | Windows 原生指针、鼠标键、滚轮和键盘输入及错误报告；进程优先级与节能降频设置 |
| `internal/panel` | Win32 配置面板（手势、灵敏度、高级 · 绑定、高级 · 识别、配置文件五页）、草稿、状态与原生文件对话框，不提供 HTTP 服务 |
| `internal/preview` | 可隐藏的实时图像与识别状态、六项灵敏度滑块 |
| `internal/overlay` | 光标旁提示：分层、点击穿透、不激活的置顶小窗，按所在显示器 DPI 绘制，内容不变时不重绘 |
| `internal/winui` | 面板与光标旁提示共用：抗锯齿画布与手形小图、视觉样式、DPI、字体、文字蒙版和窗口截图 |

配置窗口与预览独立。面板模式下关闭任一窗口只隐藏，F7 重开面板，F8 暂停/恢复，F9 或面板“退出”结束进程。面板隐藏后停止状态绘制；预览隐藏后不转换像素。暂停且预览隐藏时默认跳过推理；存在启用的 `toggle_pause` 绑定时继续观察，以便通过手势恢复。光标旁提示是独立的不激活小窗：暂停时不显示手势，按 F8 后短暂显示已暂停或已恢复；`hideHints` 只关闭手势提示。

## 手势与动作如何解耦

识别集合固定为 `fist`、`point`、`two`、`middle`、`click_pinch`、`three`、`four`、`five`、`middle_ring_pinky`、`thumb_out`。版本 3 起 `middle_ring_pinky`（后三指：中指、无名指、小指伸直，食指收起，拇指随意）取代 `ok`；`ok` 的几何定义仍在姿势表中，但不属于识别集合。版本 4 起 `four`（四指张开、拇指收起）没有默认绑定，但仍留在识别集合里：引擎只把换成另一个已识别手势当作上一个手势的释放，握拳后张成拇指收起的手掌也要算松开。其余四指张开时拇指使用更宽的门槛（开合度高于 0.25 算张开、低于 0.15 算收起，其他手型为 0.6 和 0.4），自然放松的拇指也算 `five`。禁用动作不会移除对应分类，也不会让它回落到其他手势并误触。`two_index` 是双手组合，不写进十种基础识别集合；当前不支持编辑新几何手势或训练模型。

绑定由手别、手势、触发方式、等待/重复时间、动作及其参数组成。默认预设位于 [bindings.go](../internal/control/bindings.go)，实际映射由保存的配置驱动。动作和触发能力由 [catalog.go](../internal/engine/catalog.go) 定义并供面板使用。

- 手别：`left`、`right`、`any`；`both` 仅搭配 `two_index`。
- 离散触发：`enter`、`exit`、`long_press`、`repeat` 和四方向 `swipe_*`。持续动作只使用 `hold`，离散动作不能使用 `hold`。
- 双食指支持 `pair_zoom` 和兼容的离散动作，不提供单手坐标跟随、挥动或单手当前模式的确认/取消。启用的组合在确认及保持期间占用双手；一次性动作触发后也等姿势释放才让出。没有启用的组合绑定时不抢指针。
- 选窗确认和取消通过 `confirm_action`、`cancel_action` 表达；默认右拳绑定确认，动作不再固定检查“握拳”名称。保持五指启动选窗后可放松手指，由所属手掌心选窗。
- `releaseTo` 声明动作结束后的返回姿势保护。默认左中指 Tab 返回拳时消耗该拳，避免顺带点击；先释放拳再做可点击。选窗及组合占用期间观察到的冲突姿势不会在结束后补发。
- “任意手”与具体手的覆盖沿用具体手优先规则；启用绑定的相同手别、手势和触发组合不能重复。

六项基础灵敏度分别管理左右手移动、拖拽、滚动、切屏和缩放；动作局部倍率默认 1，按对应基础倍率乘一次，不把用户基础值重复写入绑定。离散点击或按键没有灵敏度参数。切屏基础值只影响选窗步距：倍率为 1 时掌心每移动 0.6 掌长换一个窗口。单手快挥固定为 250ms 内移动 0.65 掌长、冷却 350ms，不随倍率变化；默认预设不再使用快挥。

引擎保留媒体等可配置能力，但默认映射不再使用音量、播放/暂停、前进/后退。当前配置服务拒绝启用外部程序 `open` 动作；没有可通过添加 `allowOpen` 开启的配置字段。

## 配置格式与约束

默认路径为 EXE 同目录的 `settings.json`，可用 `-config` 指定。CLI 显式传入 `-sensitivity` 会覆盖左右手移动值，显式 `-swap-hands` 会修改左右手校正；成功初始化配置服务时会保存这些值，重启继续使用。用 `go run` 时建议显式指定稳定的配置路径。

| 顶层字段 | 内容 |
|---|---|
| `version` | 当前为 `4`；版本 2、3 读取时自动升级，其他版本拒绝加载 |
| `preferences` | `moveLeft`、`moveRight`、`drag`、`scroll`、`switcher`、`zoom`、`swapHands`；六项倍率各为 0.1～5 的有限数 |
| `recognition` | 下表七项识别设置 |
| `gestures` | 上述十种基础手势 ID，必须完整且不重复，不是动作启停开关 |
| `bindings` | 最多 256 条；显式 `[]` 表示无绑定，缺失或 `null` 拒绝加载 |

| 识别字段 | 默认值 | 范围 |
|---|---:|---:|
| `voteWindowMs` | 150 | 30～1000 |
| `lostGraceMs` | 400 | 50～2000 |
| `middleConfirmMs` | 60 | 10～1000 |
| `middleRingPinkyConfirmMs` | 80 | 10～1000 |
| `fiveConfirmMs` | 150 | 10～1000 |
| `minPalmPx` | 45 | 0～200 |
| `newHandMs` | 200 | 0～1000 |

`minPalmPx` 单位为摄像头画面像素，其余为 ms。`lostGraceMs` 是手离开画面多久算撤手，期间在附近重新出现的手保持原状态。五指从其他手势直接切换时确认时间至少 200ms；确认期间掌心移动超过 0.3 掌长则重新计时，手停住才唤出。这两项不可配置。`minPalmPx` 量手腕到中指根的长度，只决定是否接收新出现的手，0 表示不限制；已跟踪的手变小时不丢弃。`newHandMs` 内新出现的手只能移动指针，其余动作等观察期结束。左右手标签稳定 500ms 后锁定，需连续 700ms 的相反判断才翻转；同一只手的重复检测（框重叠 IoU 超过 0.5，或掌心距离小于 0.6 掌长）合并为一个跟踪。这两项为固定参数。

每条绑定含 `id`、`name`、`enabled`、`hand`、`pose`、`trigger`、`holdMs`、`action`，可带 `intervalMs`、`releaseTo`。ID 为 1～40 个字母、数字、下划线或连字符；名称最多 60 个字符。`holdMs` 为 0～10000，重复间隔有效范围 50～10000，省略/0 时使用默认 400。具体触发方式会规范化其不使用的等待/重复字段。

建议通过面板导出后修改再导入。配置文件上限 1MiB，未知字段、未知动作参数、非法按键、冲突和越界值会拒绝；例如组合键参数名是 `keys`，不是 `key`。不能把局部绑定片段当作完整配置文件导入。

## 保存、迁移与运行保护

1. 面板维护独立草稿；导入和恢复默认只修改草稿，按“保存并应用”才影响运行。导出校验草稿，禁止覆盖正在运行的配置文件。
2. `Service.Apply` 检查修订号，完整校验并准备新配置，再原子写盘。验证或写盘失败保留原运行配置；旧草稿遇到其他入口更新时不能强行覆盖。
3. 成功落盘后短暂锁住控制器，释放旧拖拽/按键/Alt，保留暂停和手势消耗状态，再切换引擎与识别设置。保存、改键和 F6 不会对同一个保持姿势重发动作。
4. 预览滑块仅合并发生变化的倍率，F6 合并最新绑定后修改校正；两者与面板使用同一配置服务。修订号是进程内并发保护，不写入 JSON。
5. 首次读取旧七字段偏好时补入当前默认预设。读取版本 2 时自动升级：手势列表、绑定和 `releaseTo` 中的 `ok` 改为 `middle_ring_pinky`，默认名“右手 OK 右 Alt”改为“右手后三指 右 Alt”，`okConfirmMs` 的值转入 `middleRingPinkyConfirmMs`；仍为旧默认值的 `fiveConfirmMs`（30）和 `lostGraceMs`（200）换成新默认。读取版本 3（含由版本 2 升上来的配置）时：删除默认的四指快切绑定 `quick-next`、`quick-prev`；`scroll`（任意手三指）和 `drag`（右手两指）都还是默认手势、且右手两指/三指和左手三指的保持触发没有被其他绑定占用时，`scroll` 改为右手两指，其后补一条左手三指的 `scroll-left`，`drag` 改为右手三指，默认名称同步改掉；任一条件不满足则这几条保持原样。手势列表不变。绑定列表完全以文件内容为准，不按位置继承默认预设的动作参数。保存覆盖旧版本文件前将原文备份为 `<配置路径>.v{旧版本}.bak`（`.v1.bak`、`.v2.bak` 或 `.v3.bak`），已有备份不覆盖。配置服务启动时即写回当前版本，因此新程序一启动，旧版本文件就会被备份并覆盖。缺失配置使用默认；损坏配置报错，不自动覆盖为默认。

需回退旧程序时，先正常退出当前进程并另行保留版本 4 配置，再把旧程序能读取的备份（版本 3 程序用 `.v3.bak`，版本 2 程序用 `.v2.bak`，更早的程序用 `.v1.bak`）复制回旧程序使用的配置路径；旧程序不能读取比它新的版本。旧备份不包含后来编辑的绑定。当前版本日常恢复优先使用面板分别恢复映射、倍率或识别设置，保留左右手校正。

摄像头连续 2 秒无帧、帧或推理结果超过 200ms 时停止输入并退出；退出先释放持有输入，再给摄像头最多 2 秒清理。Windows 拒绝输入（锁屏、UAC 等安全桌面）时只释放持有输入并继续运行，日志限频记录。普通权限输入仍受 Windows 完整性级别限制。上述保护及验收结果见[面板验收记录](native-panel-validation-2026-11-17.md)，待完成项目见[文档入口](README.md)。
