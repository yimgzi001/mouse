# 文档入口

## 当前开发状态

摄像头到 Windows 输入的链路、默认手势、独立灵敏度、性能优化、Windows 原生配置面板和可持久化的手势—动作绑定均已实现。运行时使用保存的配置，默认映射只用于首次初始化或主动恢复默认。

| 范围 | 已有证据 | 尚未确认 |
|---|---|---|
| 摄像头、鼠标、滚动、切窗及键盘默认映射 | 用户在面板开发前确认真人测试无问题；关键点回归及受控 Windows 输入测试通过 | 不同光照、距离和用户的量化成功率 |
| 原生面板、保存应用、导入导出、配置迁移、双手绑定 | 全量竞态测试、静态检查、原生控件交互和 GUI 构建通过，详见验收记录 | 用户本轮面板试用；截图布局检查和文件选择器内选定文件的自动化未完成 |
| 识别修复（后三指取代 OK、五指确认、新手观察、最小掌宽、左右手锁定、重复手合并、进程优先级） | 全量竞态测试、面板/预览交互测试、参考图片关键点回归和图片回放 CPU 对比通过，详见识别修复记录；用户试用后反馈没有大问题 | 45 像素最小掌宽在不同距离下是否合适；试用中提出的五指唤出偏慢、选窗偏快见下一行 |
| 手势调整（取消四指快切、右手两指滚动、右手三指拖拽、五指唤出加快、选窗放慢、配置版本 4） | 全量竞态测试、面板/预览交互测试、静态检查通过，用户配置副本升级核对无误，详见手势调整记录 | 用户真人试用：五指唤出是否够快、是否误唤出，选窗速度和新手势是否顺手 |
| 资源占用与延迟 | 固定图片模型对比、短时进程采样 | 30 分钟空闲误触、连续 8 小时稳定性、完整操作延迟统计 |
| 产品交付 | 可运行 EXE 与配套 DLL | 安装包、正式发布；原始方案中的系统托盘尚未实现 |

“已实现”“自动化通过”“真人验收”分别记录，不用阶段测试替代长期稳定性结论。最近一轮验证为 2026-11-17 的手势调整，只有自动化测试，尚无真人试用；文档不据历史启动记录判断程序当前仍在运行。
