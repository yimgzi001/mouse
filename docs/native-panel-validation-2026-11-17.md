# 原生配置面板与绑定解耦验收记录

日期：2026-11-17。用户确认采用 Windows 原生窗口，沿用 Go + Win32，不引入网页服务、WebView 或前端运行时。

本文是该次交付的验证记录，配置值、日志与启动状态均指当时，不代表程序当前仍在运行。后续开发入口见[文档索引](README.md)，配置和模块说明见[当前架构](architecture.md)。

## 已交付

- 原生绑定列表和编辑表单：新增、删除、启停、名称、手别、手势、触发方式、确认/重复时间、动作和动态参数；返回姿势保护可按绑定配置。
- 六项基础灵敏度和五项识别时间；动作倍率与基础倍率相乘一次。保存无关字段不量化已有精度，预览滑块只提交实际改动项。
- 草稿与运行配置分离，保存即时应用、重启保留；版本冲突和无效配置不覆盖运行状态。默认映射、灵敏度、识别时间分别恢复。
- 原生 JSON 文件选择器、导入/导出；导入只修改草稿，导出不允许绕过修订保护覆盖当前运行配置。
- 固定基础识别集合独立于绑定启停，双食指是组合事件；缩放、一次性按键/点击通过双手绑定分发。组合禁用不抢占指针。
- 选窗确认/取消为显式动作，快挥可路由兼容的离散动作，不能通过固定的握拳/五指名称决定动作。
- 配置切换会释放输入、保留暂停状态与消耗/返回保护，保持姿势不会因保存或 F6 重发。原生预览支持独立隐藏，关闭面板保留草稿，F7 重开，F9/退出结束后台。
- GUI 构建不打开控制台；隐藏启动标志不会把配置窗口一起隐藏。隐藏预览不转换 RGB；暂停且没有手势恢复绑定时跳过推理，有恢复绑定时保持观察。

## 配置迁移

运行中的 `bin/settings.json` 已从旧七字段格式迁移为版本 2，旧原文保留在 `bin/settings.json.v1.bak`，未覆盖旧备份。迁移时用户最新值为左移动 0.5、右移动 0.44、拖拽 0.5、滚动 0.75、切屏 1.69、缩放 1、左右手交换 false，启动后核对保留。

默认绑定只是首次配置和“恢复默认映射”的预设，不再在调整灵敏度、F6 或启动时重建并覆盖用户绑定。十种基础识别与组合绑定的范围见设计文档；新增几何手势编辑/模型训练、安装包和发布流程不在本轮。

## 执行过的验证

```powershell
go test -race -count=1 ./...
go vet ./...
go build -ldflags="-H=windowsgui" -o bin/mouse-native-panel.exe ./cmd/mouse
go run ./cmd/visioncheck

$env:MOUSE_PANEL_TEST='1'
$env:MOUSE_PREVIEW_TEST='1'
go test -race -count=1 ./...
Remove-Item Env:MOUSE_PANEL_TEST,Env:MOUSE_PREVIEW_TEST

$env:MOUSE_LIVE_TEST='1'
go test -count=1 -run '^TestLiveDesktopPointerAndClicks$' -v ./internal/wininput
Remove-Item Env:MOUSE_LIVE_TEST
```

- 上述命令通过。原生交互全量竞态运行中，panel 包 25.868s、preview 包 3.798s；文件对话框打开/取消、实际控件编辑/保存/重载、启停、导入导出草稿、隐藏/重开/销毁、字段精度均通过。
- 配置测试覆盖旧文件迁移、备份、深拷贝、显式空绑定、错误版本/手势/按键/未知参数/NaN/冲突拒绝、写盘失败、修订冲突、真实控制器改键/禁用和重启读取。
- 输入转移测试覆盖保存时保持的左键、Tab、右 Alt、拖拽、选窗、待释放保护和 F6；动作引擎还覆盖所有挥动方向和多种离散动作的返回保护，含原始识别与稳定投票不同步的边界。
- `visioncheck` 检出预期 15 只手，平均关键点误差 0.38px、最差 1.87px。
- Windows 原生输入测试在自建临时窗口内收到一组左键和一组右键，指针从 (400,300) 移至 (422,300)，通过后恢复原指针位置。其他配置和控件测试不发送全局桌面输入。
- 独立审查发现的配置重发、触发方式保护缺口、不可达确认组合、精度损失、暂停手势无法恢复、状态行裁切和快挥返回保护缺口均已补测试后修复。
