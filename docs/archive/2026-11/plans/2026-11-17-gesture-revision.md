# 按真人试用反馈修订手势

用户已明确：右手捏合左键，左手两指右键，右手两指拖拽；音量、播放、暂停、前进、后退不再绑定；拇指向上（包括手背朝镜头）发送 Tab；只伸中指发送 Enter；双食指拉开/合拢缩放；切屏跟随需更灵活；灵敏度分别可调。

- [x] 测试并替换默认手势，使用收起其他三指的捏合，避免泛化捏合抢占滚动/五指。
- [x] 实现双食指距离缩放：冻结指针，双手平移不缩放，暂停/丢手/角色不确定时冻结或退出并重建基准；切屏优先。
- [x] 增加六项独立灵敏度：左手移动、右手移动、拖拽、滚动、切屏、缩放。本地 JSON 保存，预览滑动条修改并立即应用。
- [x] 切屏默认步距从 0.45 掌长调至 0.18，最小间隔从 120ms 调至 70ms，并保留防抖及取消保护。
- [x] 更新预览、帮助和测试；全量测试、竞态检查、静态检查、原生窗口验证后启动新版。

默认倍率：移动左/右 0.5，拖拽 0.5，滚动 1.0，切屏 2.5，缩放 1.0。倍率范围 0.1～5。原始需求文档保留存档，此次规则以用户反馈和右键确认答案为准。
