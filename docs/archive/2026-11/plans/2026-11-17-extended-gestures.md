# 扩展手势接入计划

目标：把滚动、窗口切换、拖拽、缩放、音量、媒体控制和快捷键接到当前可运行程序，验证后启动供用户试用。保留双手一指移动、左右手两指点击、0.5 运行灵敏度及实时预览。

映射：三指（食指、中指、无名指）上下滚动；五指稳定 250ms 后切窗口、左右选项、撤手确认、握拳取消；食指加小指保持 180ms 后拖拽；OK 保持 180ms 后上下缩放；拇指朝上保持 250ms 后上下调音量；拇指朝下保持 600ms 播放/暂停；拇指朝左/右保持 500ms 后执行 Alt+Left/Right。时间为投票确认后的额外等待。

## 实施结果与验证

- 所有上述动作已接入默认绑定，预览及启动日志共享完整操作表；显示每只手的当前动作和最近触发事件。
- 新增关键点驱动的滚动、拖拽、缩放、音量、媒体、快捷键和切屏测试，以及独占、丢手、取消、暂停、超时后不重开等状态测试，全部通过。
- 修复新增测试复现的问题：切屏在当前帧握拳时立即取消；左右手不确定时冻结切屏选择；超时/取消后锁住激活手势，直至释放；音量和缩放单帧最多两步，丢弃异常位移多余输出。
- 独立审查发现双手拖拽与点击会争用同一按钮；`TestOtherHandsClickCannotReleaseActiveDrag` 先复现 `[left down left down left up]`，再通过按键占用保护修复。被忽略的点击需释放手势才能重新触发，不在拖拽结束时补发。
- `go test -count=1 ./...`、最终 `go test -race -count=1 ./...`、`go vet ./...`、`go build -o bin/mouse-gestures.exe ./cmd/mouse` 均通过；构建已替换到 `bin/mouse.exe`。
- `MOUSE_PREVIEW_TEST=1 go test -race -count=1 -run TestLivePreviewCopiesFrameAndCloses -v ./internal/preview`：通过。
- 原生 `TestLiveDesktopPointerAndClicks` 首次窗口未收到按钮消息；添加失败时的输入包/引擎事件诊断后复测通过，实际光标右移 30px，测试窗口收到一次左键与一次右键。首次失败的环境原因未确定，保留诊断信息供后续排查。
- 已以 `-preview -verbose -sensitivity 0.5` 启动完整版本，保留默认左右手映射。真人扩展手势的识别手感和成功率等待用户测试。
